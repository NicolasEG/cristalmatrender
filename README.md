# CRISTALMAT

Sitio web estático completo. Incluye inicio, servicios y contacto, imágenes, catálogo de Garden Blocks, carrusel infinito, animaciones de scroll y modal para ampliar las imágenes.

## Subir a GitHub

1. Descomprimí este ZIP.
2. Creá un repositorio en GitHub.
3. Subí el contenido de esta carpeta a la raíz del repositorio. El archivo index.html debe quedar en la raíz.
4. Para publicarlo con GitHub Pages, abrí Settings → Pages, elegí Deploy from a branch y seleccioná main y / (root). Guardá y esperá a que GitHub muestre el enlace.

No requiere instalación ni compilación. También se puede subir a cualquier hosting estático.

## Archivos

- index.html: inicio y productos.
- servicios.html: servicios.
- contacto.html: contacto y consulta por WhatsApp.
- styles.css: diseño y animaciones.
- app.js: menú, carrusel, animaciones, modal y consulta por WhatsApp.
- assets/: logo, fotografías e imágenes del catálogo.
- .nojekyll: permite servir los archivos directamente en GitHub Pages.
